# Lubnan

Propuesta de sitio oficial para Restaurante Lubnan (Paseo Colón, San José). No es el sitio en producción.

**Demo:** [https://lubnan-bay.vercel.app](https://lubnan-bay.vercel.app)

La página lleva `noindex`. La carta vive en [Oddmenu](https://oddmenu.com/es/p/ilovelubnan).

Para correrlo en local:

```bash
npm install
npm run dev
```
